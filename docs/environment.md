# Environment Variables

Supported runtime options:

- `GP_MARKET`
  - Xbox market code
  - default: `US`
- `GP_LANGUAGE`
  - Xbox locale
  - default: `en-us`
- `PS_LOCALE`
  - PlayStation locale
  - default: `en-us`
- `HLTB_CONCURRENCY`
  - concurrent HLTB lookups
  - default: `4`
- `HLTB_DELAY_MS`
  - delay between HLTB requests
  - default: `250`
- `FETCH_RETRIES`
  - retry count for live catalog requests
  - default: `3`
- `FETCH_RETRY_DELAY_MS`
  - base retry delay in milliseconds
  - default: `1500`
- `PORT`
  - local server port
  - default: `4173`
- `HOST`
  - local server host
  - default: `127.0.0.1`
